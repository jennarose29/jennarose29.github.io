Category One: Software Design and Engineering

The artifact selected for this category is the event tracking mobile application developed in CS-360 in June 2025. The original application allowed users to register, log in, and manage events; however, it contained structural and security weaknesses. Passwords were stored in plain text, and user interface logic was tightly coupled with business logic, limiting maintainability and scalability.

To enhance this artifact, I implemented BCrypt password hashing to replace plain-text storage, ensuring that user credentials remain protected even if the database is compromised. This demonstrates an applied understanding of cryptographic hashing, salt generation, and secure authentication practices. Additionally, I refactored the application using the Model-View-ViewModel (MVVM) architecture. Separating the user interface, business logic, and data layers improved testability, maintainability, and long-term scalability. This enhancement reflects growth in architectural thinking, secure coding practices, and professional software design standards.

In enhancing this artifact I learned the importance of designing software with both security and maintainability in mind from the beginning. I also developed a stronger appreciation for architectural patterns and how structured design decisions significantly impact long-term code quality and scalability.

Category Two: Algorithms and Data Structures

The artifact selected for this category is a text-based adventure game developed in CS-140 in October 2023. The original implementation relied on repeated conditional statements and linear data handling to manage room navigation, player commands, and inventory tracking. While functional, the structure did not effectively demonstrate advanced algorithmic design or efficient data structure selection.

To improve this artifact, I redesigned the navigation system using a graph represented by an adjacency list. This allowed player movement to be handled through structured traversal rather than hard-coded conditional logic. I implemented a Breadth-First Search (BFS) algorithm to calculate the shortest safe path to remaining items, accessible through an optional hint command. This guarantees optimal pathfinding within an unweighted graph and demonstrates the practical application of graph theory concepts.

Additional optimizations included replacing repeated string parsing logic with a command dictionary for constant-time lookup and using a set for inventory management to improve lookup efficiency from O(n) to O(1). These enhancements demonstrate growth in algorithmic analysis, complexity evaluation, and the thoughtful selection of appropriate data structures to improve scalability and performance.

During this enhancement I learned how significantly data structure selection affects performance and scalability. I also strengthened my ability to evaluate time complexity and intentionally redesign systems using more efficient algorithmic approaches.

Category Three: Databases

The artifact selected for this category is the CS340 Dog Dashboard project, originally completed in June 2025. This project involved managing and querying structured relational data to support an interactive user interface. The original implementation successfully demonstrated database connectivity and basic query functionality.

The enhancement focused on improving query efficiency, refining relational schema design, and strengthening integration between the database and application layers. Queries were optimized to reduce redundancy and improve performance, and additional validation mechanisms were incorporated to enhance data integrity. These improvements demonstrate an understanding of scalable database design, structured data management, and the importance of maintaining consistency between application logic and backend systems.

While enhancing this artifact, I gained a deeper understanding of how database design decisions directly impact application performance and reliability. I also learned to approach database development with greater attention to normalization, integrity constraints, and long-term scalability.
