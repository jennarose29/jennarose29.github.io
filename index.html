Category Two: Algorithms and Data Structures

The Algorithms and Data Structures artifact I selected is the Text-Based Adventure Game that I originally developed in CS 140. The game was created as an introductory programming project where users navigate through rooms, collect items, and avoid zombies in order to win. In the original version, room navigation relied heavily on static conditional statements and basic dictionary structures to move between locations. While the game functioned correctly and met the original assignment requirements, it reflected an early stage in my understanding of algorithmic design and data structure selection.

I selected this artifact because it clearly demonstrates measurable growth in my ability to apply algorithmic principles and structured data modeling. The original implementation used repetitive conditional logic for navigation, which worked for a small number of rooms but would not scale efficiently if the game expanded. To improve this, I redesigned the navigation system using a graph-based room model represented by an adjacency list. Each room functions as a node, and directional connections are stored as edges within a dictionary structure. This change significantly improves scalability and maintainability, since new rooms and connections can now be added without restructuring large sections of code. This enhancement showcases my understanding of abstraction, data modeling, and the importance of choosing appropriate data structures.

Another major enhancement was implementing a Breadth-First Search (BFS) algorithm to create a hint system for the player. The BFS algorithm calculates the shortest path to the nearest uncollected item and provides guidance when requested. I used a deque structure from the collections module to ensure efficient O(1) queue operations during traversal. This improvement demonstrates my ability to apply theoretical algorithm concepts in a practical and user-focused way. Instead of simply adding features, I designed a solution that enhances usability while maintaining algorithmic efficiency. The addition of BFS reflects stronger problem-solving skills and a deeper understanding of time complexity and traversal strategies.

Enhancing this artifact was more challenging than I initially expected. Converting static navigation logic into a graph structure required me to rethink how I approached program design. I had to carefully manage visited nodes to prevent infinite loops and ensure that the BFS algorithm returned accurate shortest paths. Although I had learned about search algorithms in coursework, implementing one in an existing project required a more practical and applied understanding. Through this process, I gained a deeper appreciation for how data structure choices directly impact scalability, readability, and performance.

By transforming a basic navigation game into a graph-based system with algorithmic pathfinding, I was able to demonstrate growth in complexity, efficiency, and professional coding practices. This enhancement aligns with the course outcomes related to designing and evaluating computing solutions using algorithmic principles. It also reflects my development from writing functional beginner-level programs to designing structured and scalable systems that apply core computer science concepts effectively.

Category Three: Databases

The database artifact I selected is the Dog Dashboard application that I originally developed in CS 340: Client/Server Development. The project was created to allow users to search and filter rescue dogs using a MongoDB database. The application performs basic CRUD operations and retrieves data based on simple search criteria such as rescue type, breed, and age. I selected this artifact because it provided a solid foundation for demonstrating more advanced database concepts while allowing me to significantly expand its functionality beyond the original requirements. Enhancing this artifact allows me to showcase my growth in database design, querying, and performance optimization, since originally completing the course

I focused my enhancement efforts on improving the backend database layer of the application. In its original form, the application relied on basic MongoDB find() queries that performed full collection scans. While this worked for small datasets, it was inefficient and did not scale well as the database grew. Additionally, the application did not provide any way to analyze or summarize the data beyond simple filtering. To address these limitations, I implemented advanced MongoDB aggregation pipelines and indexing strategies. I added analytics functions that generate statistics such as breed distributions, age ranges, and rescue type summaries. These enhancements demonstrate my ability to move beyond basic CRUD operations and apply more advanced database querying techniques used in real-world applications.

Another major enhancement was the implementation of database indexing to improve performance. I created single-field and compound indexes on frequently queried fields such as rescue type, breed, and age. This optimization significantly improves query efficiency by reducing the number of documents MongoDB must scan to return results. I also added optimized read methods and query analysis using MongoDB’s explain() functionality, which allowed me to examine execution statistics and verify that indexes were being used correctly. These changes demonstrate my understanding of how database performance is affected by query design and indexing decisions.

Enhancing this artifact was more challenging than I initially expected. While I was familiar with basic MongoDB queries, I had not previously worked extensively with aggregation pipelines or query optimization. Designing multi-stage pipelines using operators such as $match, $group, $sort, and $bucket required careful planning and testing to ensure accurate results. I also had to troubleshoot issues related to indexing and local database configuration while transitioning from the SNHU Apporto environment to a local MongoDB instance. Through this process, I gained a deeper understanding of how MongoDB processes queries and how thoughtful database design can greatly improve application performance. This enhancement strengthened my database skills and helped me better understand how to design efficient, scalable data-driven applications. By transforming a basic search application into one that supports analytics and optimized queries, I was able to demonstrate professional-level database practices that align with the course outcomes and my growth as a computer science student.
